# Adv. Shikhar Mishra – static website

Single-file static site (`index.html`). No build step.

## Deploy on Vercel
1. Push this folder to GitHub, then import the repo in Vercel (Framework Preset: **Other**, no build command, output directory blank), **or**
2. Run `npx vercel --prod` inside this folder.

## Edit your details
Search `index.html` for `CONFIG` – phone, email, WhatsApp number, address and enrolment details are in one block at the bottom of the file. Also replace the placeholder text marked `[ ... ]`.
